# Scripts Notes

This file applies to `scripts/`.

## Scope

- This directory owns repo-level shell entry points for code generation, formatting, linting, and dependency startup.

## Scripts Reference

| Script                       | Purpose                                                                                                                                                                                   |
|------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `generate-graphql.sh`        | Exports per-API GraphQL subgraph schemas, packs subgraph packages, composes the federated gateway schema, and updates Relay init/schema files. Run this after any backend GraphQL change. |
| `format.sh`                  | Runs code formatters across the repo.                                                                                                                                                     |
| `lint.sh`                    | Runs JetBrains `inspectcode` static analysis on the .NET solution.                                                                                                                        |
| `start-dependencies.sh`      | Starts all local development infrastructure dependencies.                                                                                                                                 |
| `start-dependencies-min.sh`  | Starts the minimal set of local infrastructure dependencies needed for lightweight development.                                                                                           |
| `update-dotnet-tools.sh`     | Updates the locally pinned .NET tools (manifested in `.config/dotnet-tools.json`).                                                                                                        |
| `update-web-npm-packages.sh` | Updates web workspace dependency and peer-dependency ranges, refreshes the lockfile, and verifies shared version synchronization.                                                         |

## Important Notes

- Event metadata is **not** generated by any script in this directory. Event protobuf generation happens by building
  `shared/Api.Shared.Clients/Api.Shared.Clients.csproj`.
- Always use `generate-graphql.sh` for backend GraphQL schema regeneration — do not run `dotnet run -- schema export`
  per API individually as a substitute.
- The preferred umbrella entry point is `make generate` from the repo root, which runs:
    1. `api-definitions/generate.sh` (events + OpenAPI)
    2. `scripts/generate-graphql.sh` (GraphQL)
    3. `web/apps/webapp/scripts/generate.sh` (web TypeScript clients)

## Agent Rule

- Do not add domain-specific business logic to scripts in this directory.
- Keep scripts focused on generation, formatting, linting, and local-dev dependency management.
- After editing `generate-graphql.sh`, verify the script still composes the gateway schema and updates all affected
  test/init schema files.
