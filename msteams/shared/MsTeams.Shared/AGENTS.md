# MsTeams Shared Library Agent Notes

This file applies to `msteams/shared/MsTeams.Shared`.

## Purpose

- `MsTeams.Shared` is the core domain library for the msteams domain.
- It contains: services, repositories, workflows, activities, models, mappers, database context, and event publishers.
- Consumed by `MsTeams.Api`, `MsTeams.Jobs`, `MsTeams.Processors`, and `MsTeams.Infrastructure`.

## Key Conventions

- Repository factory pattern: use `IRepositoryFactory` for scoped data access.
- Workflow IDs: generated by `WorkflowIdService` in this library — do not reconstruct IDs inline at call sites.
- Outbox pattern: Kafka and Temporal side effects are written to the outbox tables in this library's transactions.
- Mappers: use the domain mappers for converting between domain models and event/API shapes.

## Agent Rule

- Changes here affect all msteams domain hosts simultaneously.
- Prefer backward-compatible changes to repositories and services.
- Keep workflow ID logic centralized in `Services/WorkflowIdService.cs`.
- Read the parent `msteams/shared/AGENTS.md` for domain-level rules before making changes here.
