# Teams Review QA

Use this page to review Teams Help before publishing or adding screenshots.

## Product Review

| Question                                                    | Pass condition                                                            |
| ----------------------------------------------------------- | ------------------------------------------------------------------------- |
| Does the overview explain Teams purpose?                    | A reader knows Teams is for private organization work.                    |
| Are private locations separated from marketplace locations? | Teams does not explain public selling as private setup.                   |
| Are teams, members, and access explained clearly?           | Readers understand organization membership and role-dependent visibility. |
| Are analytics and availability described safely?            | Pages explain purpose without inventing formulas.                         |
| Is SSO explained without exposing configuration detail?     | SSO is described as sign-in, not internal security setup.                 |

## Support Review

| Question                                             | Pass condition                                                   |
| ---------------------------------------------------- | ---------------------------------------------------------------- |
| Can admins troubleshoot access?                      | Access and permissions page gives a clear check order.           |
| Can support triage integrations?                     | Slack, Microsoft Teams, and SSO handoff templates exist.         |
| Are common booking/location/resource issues covered? | Troubleshooting and examples cover likely support paths.         |
| Are private member details protected?                | Pages warn against real member data in screenshots and messages. |

## Engineering Review

| Question                                      | Pass condition                                                      |
| --------------------------------------------- | ------------------------------------------------------------------- |
| Does help match route ownership?              | Teams pages cover private organization routes only.                 |
| Are unsupported permission specifics avoided? | Exact permission matrix is marked as a content gap.                 |
| Are integrations public-safe?                 | No provider secrets or configuration internals are exposed.         |
| Are screenshot rules clear?                   | Screenshot plan requires demo data and hidden SSO/provider details. |

## Copy Review

| Question                | Pass condition                                                  |
| ----------------------- | --------------------------------------------------------------- |
| Is the writing simple?  | Admin guidance uses checklists and examples.                    |
| Is it American English? | No British spelling in operator-facing copy.                    |
| Is it practical?        | Pages explain what to check before changing organization setup. |
