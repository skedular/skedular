# Teams Content Gaps

Some Teams workflows need product review before the help should describe them in exact detail.

## Current Gaps

| Gap                            | What we explain now                                                 | What needs review                                                 |
| ------------------------------ | ------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Permission matrix              | Visible actions depend on organization access.                      | Exact role and permission behavior for every admin/member action. |
| Resource field detail          | Resources are bookable private items.                               | Field-by-field setup rules and validation messages.               |
| Microsoft Teams failure states | Follow the provider flow and retry or contact an admin if it fails. | Provider-specific error messages and recovery steps.              |
| Analytics metric definitions   | Analytics and availability help admins review workplace usage.      | Exact formulas, labels, and examples for each metric.             |

## How To Use This Page

If a task depends on one of these details, use the product UI and your organization policy as the source of truth until the help is expanded.

## What Is Safe To Say Now

The first-version Teams help can safely explain:

- what Teams is for
- how private organizations differ from marketplace organizations
- where admins manage bookings, locations, resources, teams, members, settings, integrations, analytics, and SSO
- why actions may depend on access
- what information to check before changing private workplace setup

The first-version help should not invent:

- exact role permission tables
- provider-specific SSO, Slack, or Microsoft Teams failure messages
- final metric formulas
- every field-level validation rule for resource setup

## Review Needed Later

When screenshots are added, review every page for real labels and visible states. If a screenshot shows a label that differs from this help page, update the help page to match the product UI.
