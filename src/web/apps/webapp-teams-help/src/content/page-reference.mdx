# Teams Page Reference

This page explains the main Teams pages from the private organization point of view.

## Organization Home

Use this page as the starting point for private organization work.

Check:

- organization name
- main navigation
- visible pages for your access level
- whether you are in Teams, not Spaces

## Add Private Organization

Use this page to create or start a private organization setup.

Check:

- organization name
- admin ownership
- setup requirements
- whether the organization should be private rather than marketplace-facing

## Admin Page

Use this page for organization management.

Check:

- organization-level settings
- available admin actions
- setup sections that affect members
- changes that may affect bookings, locations, or access

## Bookings Page

Use this page to review internal bookings.

Check:

- booking date
- person or team
- location
- resource
- status
- whether the booking is one-time or recurring

## Add Booking Page

Use this page to create a private booking.

Check:

- selected person or team
- selected location
- selected resource
- date and time
- recurrence if shown
- conflicts or blocked times

## Booking Detail Page

Use this page to understand one internal booking.

Check:

- owner
- related team
- location
- resource
- date and time
- current status
- visible actions

## Locations Page

Use this page to review private locations.

Check:

- location list
- active locations
- naming consistency
- which locations need resources

## Add Private Location Page

Use this page to create a private location.

Check:

- name
- address or internal site label
- access expectations
- whether resources or floor plans will be needed

## Location Detail Page

Use this page to review or manage one location.

Check:

- location details
- resources
- zones
- floor plan information
- booking context

## Add Resource Page

Use this page to create a resource for private booking.

Check:

- resource name
- location
- capacity or purpose
- availability
- access expectations

## Teams Page

Use this page to review groups inside the organization.

Check:

- team names
- membership
- whether teams match real organization groups
- whether team setup supports booking needs

## Add Team Page

Use this page to create a new internal group.

Check:

- team name
- purpose
- members to add later
- access expectations

## Team Detail Page

Use this page to review one team.

Check:

- members
- related bookings or context when shown
- whether the team still matches the real group

## Users Page

Use this page to review organization people.

Check:

- member list
- invited users
- visible roles or access
- users who need help signing in

## User Detail Page

Use this page to review one person's organization context.

Check:

- identity
- organization access
- team membership
- related activity when shown

## Analytics Page

Use this page to review trends.

Check:

- date range
- location filters
- usage patterns
- metric meaning before making decisions

## Availability Dashboard

Use this page to review capacity.

Check:

- location
- resource demand
- busy times
- unused capacity
- places that may need setup changes

## Settings Page

Use this page for account or organization preferences available to your role.

Check:

- preferences
- organization context
- whether the setting belongs in Teams

## Notifications Page

Use this page for recent updates.

Check:

- booking updates
- organization updates
- integration updates
- links back to records

## Slack And Microsoft Teams Pages

Use these pages to connect or use collaboration tools.

Check:

- correct workspace or tenant
- correct organization
- install success page
- provider permissions

## SSO Sign-In Page

Use this page when the organization requires identity provider sign-in.

Check:

- correct work account
- organization domain or identity provider context
- whether sign-in returns to the organization
