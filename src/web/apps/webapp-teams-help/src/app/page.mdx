# Teams Help

Teams Help is for private organizations that use Skedular to manage internal locations, resources, bookings, people, integrations, and workplace reporting.

Use this help site when the work belongs inside a company or private organization. That includes adding a private location, booking a shared resource, managing teams and members, using SSO, or checking internal availability.

## Start Here

- **Set up the organization:** Learn about organization entry, admin pages, sign-in, and access.
- **Manage bookings and places:** Understand private bookings, locations, resources, zones, and floor plans.
- **Manage people:** Learn how teams, members, notifications, settings, Slack, and Microsoft Teams fit together.
- **Review usage:** Learn what analytics, availability, and SSO pages are for.

## Use Another Help Site When

- You are a customer booking from a public marketplace. Use Customer Help.
- You run a co-working or marketplace business, publish products, manage payments, or handle marketplace refunds. Use Spaces Help.
