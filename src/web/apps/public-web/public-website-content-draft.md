# Skedular Public Website Master Specification v2

## Purpose

This document defines the complete vision, architecture, content strategy, SEO strategy, accessibility requirements, AI discoverability requirements, feature inventory, competitive positioning, and implementation requirements for the next generation of the Skedular public website.

This document is intended to be used by:

- Engineers
- Designers
- Product Managers
- Technical Writers
- Marketing Teams
- AI Coding Agents (Codex, Copilot, Claude Code, Cursor)

The website should communicate the full Skedular ecosystem while remaining simple and intuitive for first time visitors.

---

# Vision

Skedular is a workspace operating system.

It enables individuals, organizations, and workspace operators to discover, book, manage, and monetize workspace resources through a single platform.

Unlike most competitors, Skedular supports:

- Public workspace discovery
- Private workplace management
- Co-working operations
- Resource commerce
- Payments
- Billing
- Invoicing
- Team collaboration

within a single ecosystem.

# Final Positioning Statement

Skedular is a workspace operating system that helps people find workspace, organizations manage workplaces, and operators run workspace businesses through a unified platform.

The public booking experience is the primary customer experience.

Teams and Spaces are business products that extend the platform for organizations and operators.
