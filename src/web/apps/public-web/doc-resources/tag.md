# Tags

## Overview

Tags are flexible, organization-wide labels that can be assigned to resources to describe their features, capabilities, or characteristics.

Unlike locations or zones, tags have no hierarchy or structure. They are simple labels that help classify resources and make them easier to search and discover.

Every organization can define its own tags based on its business needs.

Examples include:

- Dual Monitor
- Standing Desk
- Quiet Space
- Whiteboard
- Video Conferencing
- Accessible
- Projector
- Air Conditioning
- Natural Light
- Electric Vehicle Charger

There are no restrictions on what a tag represents. You are free to create any labels that help your users identify the right resource.

---

# How Tags Work

Tags are created once at the organization level and can then be assigned to any resource within the organization.

A resource can have:

- No tags
- One tag
- Multiple tags

Because tags are completely independent of each other, they provide a flexible way to describe resources without affecting your organizational structure.

For example:

| Resource       | Tags                           |
| -------------- | ------------------------------ |
| Desk A12       | Standing Desk, Dual Monitor    |
| Meeting Room 1 | Whiteboard, Video Conferencing |
| Desk B08       | Quiet Space                    |
| Parking Bay 3  | Electric Vehicle Charger       |

---

# Why Use Tags?

Tags help users quickly understand the features of a resource before making a booking.

They are commonly used to:

- Describe equipment available with a resource
- Highlight accessibility features
- Identify special facilities
- Categorize workspaces
- Improve search results
- Help users find resources that meet their specific requirements

Instead of browsing every available resource, users can search or filter using tags to find exactly what they need.

---

# Managing Tags

Tags are managed at the organization level.

Only users with the appropriate administrative permissions can create, edit, or delete tags.

Tags are managed from:

**Admin → Tags**

From this page administrators can:

- View all tags
- Create a new tag
- Edit an existing tag
- Delete a tag

Changes become available immediately throughout the organization.

---

# Creating a Tag

To create a new tag:

1. Open **Admin**.
2. Select **Tags**.
3. Click **Add Tag**.
4. Enter the tag name.
5. Save the tag.

The tag is now available to assign to resources.

---

# Editing a Tag

To rename a tag:

1. Open **Admin**.
2. Select **Tags**.
3. Select the tag.
4. Update its name.
5. Save your changes.

Resources that already use the tag will automatically display the updated name.

---

# Deleting a Tag

If a tag is no longer required:

1. Open **Admin**.
2. Select **Tags**.
3. Choose the tag.
4. Delete it.

Deleting a tag removes it from the organization and from every resource that was using it.

---

# Assigning Tags to Resources

Tags are assigned while editing a resource.

Administrators can select any combination of available tags.

There is no limit to how many tags can be assigned to a resource.

For example:

- A standing desk with two monitors may have:
  - Standing Desk
  - Dual Monitor

- A meeting room may have:
  - Whiteboard
  - Video Conferencing
  - Air Conditioning

- A parking space may have:
  - Electric Vehicle Charger

Resources are not required to have any tags.

---

# Searching with Tags

One of the primary purposes of tags is to improve resource discovery.

Users can search or filter resources using one or more tags to quickly find resources that match their requirements.

For example, a user looking for a desk with two monitors can search for:

- Dual Monitor

Or someone looking for a meeting room with presentation equipment can search for:

- Projector
- Whiteboard

Tags make it easier to locate suitable resources without manually reviewing every available option.

---

# Best Practices

To keep tags useful and consistent:

- Keep names short and descriptive.
- Use a consistent naming convention across your organization.
- Avoid creating duplicate tags with similar meanings.
- Create tags that describe features rather than individual resources.
- Periodically review unused tags and remove those that are no longer needed.

---

# Things to Know

- Tags are created at the organization level.
- All locations within the organization can use the same tags.
- Resources can have zero, one, or many tags.
- Tags are optional.
- Renaming a tag updates it everywhere it is used.
- Deleting a tag removes it from every resource that references it.
- Tags have no hierarchy or parent-child relationship.

---

# Tags vs Zones

Although tags and zones both help organize resources, they serve different purposes.

| Zones                                            | Tags                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| Represent a physical or logical area.            | Represent characteristics or features of a resource.               |
| Usually describe where a resource belongs.       | Usually describe what a resource offers.                           |
| Examples: First Floor, East Wing, Building A.    | Examples: Dual Monitor, Standing Desk, Whiteboard.                 |
| Help organize resources by location or grouping. | Help users search and filter resources by capability or attribute. |

Organizations commonly use both together.

For example:

**Desk A12**

- Zone:
  - First Floor

- Tags:
  - Standing Desk
  - Dual Monitor
