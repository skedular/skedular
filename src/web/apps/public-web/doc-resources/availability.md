# Availability

## Overview

Availability provides a real-time view of when resources can be booked.

It allows users and administrators to quickly see which resources are available, already booked, or unavailable for a selected date.

The Availability view is available in:

- **Skedular Teams**
- **Skedular Spaces**
- **Skedular Host**

It is designed to give a complete picture of resource usage across an organization.

---

# Why Availability Exists

Availability helps users answer a simple question:

**"What can I book on this date?"**

Instead of checking resources individually, the Availability view displays the booking status of every resource in one place.

This makes it easy to:

- Find available resources.
- Identify booked resources.
- Understand workspace utilisation.
- Navigate directly to a resource's floor plan.
- Plan future bookings.

---

# Viewing Availability

Availability is viewed for a specific date.

Users can change the selected date to view availability for:

- Today
- Past dates
- Future dates

This allows organizations to review both historical bookings and future reservations.

---

# Filtering Availability

Availability can be filtered to help users find resources more quickly.

Depending on the product, available filters may include:

- Date
- Location
- Resource status

Additional filters may become available in future releases.

---

# Resource Status

Each resource displays its current status for the selected date.

Typical statuses include:

- Available
- Booked
- Unavailable

These statuses are calculated using:

- Existing bookings
- Opening hours
- Resource availability rules

The displayed status updates automatically as bookings change.

---

# Resource Information

Each resource displayed in the Availability view includes useful information such as:

- Resource name
- Resource type
- Location
- Current status
- Total booked time for the selected day

For example:

- Desk A12
- Available
- Auckland Office → Level One
- 120 of 1,440 minutes booked

This provides a quick overview of how heavily each resource is being used.

---

# Viewing Historical Availability

Availability is not limited to today's bookings.

Users can navigate to previous dates to see:

- Which resources were booked.
- Which resources were available.
- Historical utilisation.

This is useful when reviewing office attendance or investigating previous bookings.

---

# Viewing Future Availability

Users can also navigate to future dates.

This makes it easy to:

- Plan upcoming office attendance.
- Find available meeting rooms.
- Reserve resources in advance.
- Check future capacity.

Availability reflects all confirmed bookings for the selected day.

---

# Floor Plan Integration

For locations with floor plans, the Availability view provides direct access to the visual layout.

Users can open the floor plan to:

- See where resources are located.
- View resource availability visually.
- Select resources directly from the map.
- Understand the physical layout of the workplace.

This provides a more intuitive booking experience than viewing a simple list of resources.

---

# How Availability Is Calculated

Availability is determined using several factors, including:

- Resource opening hours.
- Location opening hours.
- Existing bookings.
- Booking conflicts.
- Resource-specific availability rules.

A resource is considered available only when it can be booked during the selected period.

---

# Managing Availability

Availability is automatically maintained by the Skedular booking engine.

Administrators do not manually update availability.

Whenever:

- A booking is created,
- A booking is modified,
- A booking is cancelled,
- Opening hours change,

the availability of the affected resources is automatically recalculated.

---

# Best Practices

To get the most accurate availability information:

- Keep location opening hours up to date.
- Configure resource-specific opening hours where required.
- Cancel bookings that are no longer needed.
- Keep resources assigned to the correct locations.
- Regularly review future bookings for resource planning.

---

# Things to Know

- Availability is available in **Skedular Teams**, **Skedular Spaces**, and **Skedular Host**.
- Availability is viewed one date at a time.
- Users can view past, current, and future availability.
- Availability is automatically updated whenever bookings change.
- Resources display their current booking status.
- Availability integrates with floor plans where available.
- Availability respects location and resource opening hours.

---

# Example

An employee wants to find a meeting room for Thursday.

They open the **Availability** page, select Thursday's date, and filter to the Auckland office.

The system immediately displays all meeting rooms together with their current status.

Room 1 is already booked.

Room 2 is available.

The employee selects **View Floor Plan**, sees where Room 2 is located, and creates a booking directly from the floor plan.
