## Before you begin

Start with a private Organization and the people who will use its workplace. Keep the first setup small so you can confirm access and Booking habits before a wider rollout. This guide is written for the person setting up the Organization; if an administrator has already created it, accept their invitation and select that Organization instead.

## Set up your workplace

1. Create a private Organization for the workplace, or accept an invitation to an existing private Organization. The Organization is the boundary for its Locations, Resources, people, and Bookings.
2. Add a Location, then add the desks, rooms, parking spaces, or other Resources people should be able to book. See [Resources](/docs/shared/core-concepts/resources) for the shared Resource model.
3. Invite the people who need access to the Organization. Create Teams and invite people to those Teams when a shared group or access boundary is useful; Teams are optional for a first Booking. See [Users](/docs/shared/core-concepts/users) and [Teams](/docs/shared/core-concepts/teams) for the shared models.
4. Set the Location's opening hours and, when needed, configure custom opening hours for a Resource. Then check that Resources are available at the times you expect; see [Availability](/docs/shared/core-concepts/availability) for the platform rules.
5. Optional: add a Floor Plan if a visual workplace layout will help people choose a Resource. See [Floor Plans](/docs/shared/core-concepts/floor-plans).
6. Create your first private Booking for a Resource and confirm that it appears in the private Booking experience. See [Bookings](/docs/shared/core-concepts/bookings) for universal Booking rules.

The shortest path for an administrator is Organization → Location → Resources → first Booking. Invite other Users when they need access, and add Teams, Resource-specific hours, or a Floor Plan as the workplace grows.
