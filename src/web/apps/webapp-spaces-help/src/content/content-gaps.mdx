# Spaces Content Gaps

Some Spaces workflows need product review before the help should describe them in exact detail.

## Current Gaps

| Gap                                     | What we explain now                                          | What needs review                                                                |
| --------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| Direct refund route behavior            | Refund work belongs to Spaces from the operator side.        | Direct route availability, final labels, and approved examples.                  |
| Microsoft Teams marketplace-public flow | Microsoft Teams can support operator workflows.              | Exact marketplace-public states inside Microsoft Teams.                          |
| Payment setup failures                  | Use the product UI and provider flow.                        | Provider-specific error states, retry rules, and safe troubleshooting copy.      |
| Subscription and renewal status labels  | Operators can review recurring purchases and visible status. | Final labels and examples for renewal, cancellation, refund, and payment states. |

## How To Use This Page

If a guide points here, the workflow is real but needs exact product or support review before public help should go deeper.
