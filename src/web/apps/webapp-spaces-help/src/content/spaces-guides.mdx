# Spaces Task Guides

These guides cover the main marketplace operator workflows.

## Enter A Marketplace Organization

1. Sign in with the operator account.
2. Open the marketplace organization link or choose the organization from the app.
3. Check that the organization name is correct.
4. Open the page you need: setup, locations, products, bookings, subscriptions, payments, analytics, or settings.

> Screenshot needed: Spaces organization home page with main navigation.

Expected result: you are inside the correct marketplace organization.

## Add A Marketplace Organization

1. Open the add marketplace organization page.
2. Enter the organization details required by the form.
3. Review the setup summary.
4. Finish the flow and open the new organization.

> Screenshot needed: Add marketplace organization form.

Expected result: the organization is ready for marketplace setup.

## Complete Marketplace Setup

1. Open marketplace setup.
2. Review public marketplace information.
3. Complete required readiness steps shown by the app.
4. Save changes.

> Screenshot needed: Marketplace setup page with readiness or public profile sections.

Expected result: the marketplace setup page shows what is complete and what still needs work.

## Add A Location Or Resource

1. Open locations.
2. Add a marketplace location when needed.
3. Open the location detail page.
4. Add resources that customers or operator bookings can use.
5. Review zones or floor plan information when available.

> Screenshot needed: Marketplace location detail page with resources and floor plan entry points.

Expected result: the location and resources can support products and bookings.

## Create A Product

1. Open products.
2. Choose add product.
3. Enter the product name, location or resource context, and selling rules required by the form.
4. Review whether it supports one-time booking, subscription, or both.
5. Save the product.

> Screenshot needed: Product add form with offer type and availability fields.

Expected result: the product appears in the products list and can be opened.

## Review A Booking

1. Open bookings.
2. Find the booking.
3. Open the booking detail page.
4. Review the customer, product, time, status, and visible action area.

> Screenshot needed: Spaces booking detail page with status and action area.

Expected result: the operator can understand what happened and what needs attention.

## Review A Subscription

1. Open subscriptions.
2. Find the subscription.
3. Open the subscription detail page.
4. Review the product, customer, schedule, status, and visible action area.

> Screenshot needed: Spaces subscription detail page with recurring schedule information.

Expected result: the operator can understand the recurring purchase and any next step.

## Review Refund Work

1. Open the refund area when it is available.
2. Find the refund or related booking/subscription.
3. Review the customer-facing reason and visible status.
4. Follow the product UI and organization process.

> Screenshot needed: Spaces refund list or refund detail page with demo data.

Expected result: refund work is reviewed without exposing private payment or accounting details.

## Set Up Payments

1. Open bank account or Stripe Connect account pages when your organization uses them.
2. Follow the product UI and provider flow.
3. Return to Skedular after the provider step.
4. Check the visible setup status.

> Screenshot needed: Payment setup entry page with sensitive details hidden.

Expected result: payment setup is connected or shows a clear next step.

## Connect Slack Or Microsoft Teams

1. Open the Slack or Microsoft Teams install page.
2. Follow the provider flow.
3. Return to Skedular after the success page.
4. Open your marketplace organization from the integration if that is part of your workflow.

> Screenshot needed: Spaces integration install entry and success page.

Expected result: the integration is connected or shows a retry/support path.

## Review Analytics Or Availability

1. Open analytics or the availability dashboard.
2. Choose the marketplace organization context.
3. Review demand, usage, or capacity information.
4. Use the result to adjust products, resources, or operations.

> Screenshot needed: Spaces analytics and availability dashboard pages.

Expected result: operators can understand marketplace and co-working activity.

## Use SSO

1. Open the organization SSO sign-in page.
2. Continue with the work account your organization expects.
3. Complete provider sign-in.
4. Return to the organization page.

> Screenshot needed: Spaces SSO sign-in entry.

Expected result: you are signed in through the organization identity flow.
