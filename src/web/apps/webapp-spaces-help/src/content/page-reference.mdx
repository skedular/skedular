# Spaces Page Reference

This page explains the main Spaces pages from the marketplace operator point of view.

## Organization Home

Use this page as the starting point for marketplace operations.

Check:

- organization name
- operator navigation
- marketplace setup state
- whether you are in Spaces, not Teams

## Add Marketplace Organization

Use this page to create a marketplace organization.

Check:

- public organization name
- owner/admin details
- marketplace purpose
- whether the organization will need payments

## Admin Page

Use this page for operator organization setup.

Check:

- organization settings
- public readiness
- admin-only actions
- setup sections that affect customer-facing behavior

## Marketplace Setup Page

Use this page to prepare the public marketplace side.

Check:

- public profile details
- readiness steps
- customer-facing information
- missing setup items
- whether products can be safely published

## Locations Page

Use this page to review marketplace locations.

Check:

- location list
- public readiness
- which locations have products
- which locations need resources

## Add Marketplace Location Page

Use this page to create a location customers may book from.

Check:

- customer-friendly name
- public address or place information
- operator ownership
- whether the location should be visible to customers

## Location Detail Page

Use this page to manage one location.

Check:

- public details
- resources
- zones
- floor plans
- connected products
- booking readiness

## Add Resource Page

Use this page to create a bookable resource.

Check:

- resource name
- location
- capacity or purpose
- whether it should be sold publicly
- availability expectations

## Products Page

Use this page to review marketplace offers.

Check:

- product list
- product readiness
- one-time or recurring behavior
- location/resource connection
- public naming

## Add Product Page

Use this page to create an offer customers can buy.

Check:

- product name
- description
- location/resource connection
- availability rules
- price or payment information when shown
- booking/subscription behavior

## Product Detail Page

Use this page to review one offer.

Check:

- public description
- rules
- status/readiness
- related location or resource
- customer-facing behavior

## Bookings Page

Use this page to review operator bookings.

Check:

- customer
- product
- location
- date and time
- status
- visible next action

## Add Booking Page

Use this page when the operator needs to create a booking directly.

Check:

- customer or user
- product
- location/resource
- date and time
- payment or policy expectations shown by the UI

## Booking Detail Page

Use this page for one booking record.

Check:

- customer
- product
- location/resource
- status
- visible payment signal
- cancellation/refund context
- next action

## Subscriptions Page

Use this page to review recurring customer purchases.

Check:

- customer
- product
- status
- renewal or recurring schedule
- related bookings when shown

## Subscription Detail Page

Use this page for one recurring purchase.

Check:

- product
- customer
- current period
- renewal state
- related bookings
- cancellation/refund context

## Refunds Page

Use this page when refund work is available.

Check:

- related booking or subscription
- customer request
- visible status
- policy context
- next operator action

## Bank Account Page

Use this page for payment setup where available.

Check:

- organization context
- setup status
- visible next step
- whether an authorized payment owner is signed in

Do not share bank details in screenshots.

## Stripe Connect Account Page

Use this page for provider-connected payment setup where available.

Check:

- connection status
- provider return state
- visible next step
- whether the correct operator account is used

## Analytics Page

Use this page to review marketplace trends.

Check:

- date range
- product filters
- location filters
- demand or usage signals

## Availability Dashboard

Use this page to review whether customers can book what you sell.

Check:

- resource capacity
- busy periods
- unavailable products
- locations that need setup work

## Users Page

Use this page to review customer/operator user context.

Check:

- customer records
- access context
- related activity when shown

## Slack, Microsoft Teams, And SSO Pages

Use these pages for connected tools and sign-in.

Check:

- correct organization
- correct external account
- successful provider return
- whether the route is a Spaces route
