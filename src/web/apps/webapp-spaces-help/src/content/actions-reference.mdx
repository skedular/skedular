# Spaces Actions Reference

This page explains common operator actions.

## Add Marketplace Organization

Use this when an operator is preparing to sell or manage marketplace/co-working access.

Before:

- confirm this is marketplace work
- know public organization name
- know payment needs

After:

- open marketplace setup
- add locations

## Add Location

Use this when customers need a public place to browse or book.

Before:

- choose customer-friendly name
- check address/public details
- decide whether it should be public

After:

- add resources
- review floor plan/zone needs

## Add Resource

Use this when a product needs something bookable.

Before:

- choose location
- define resource purpose/capacity
- decide if customers should see it

After:

- connect it to products
- check availability

## Add Product

Use this when customers need an offer to book or subscribe to.

Before:

- connect location/resource
- choose one-time or recurring behavior
- check price/payment expectations
- write clear customer copy

After:

- review product detail
- check customer-facing readiness

## Review Booking

Use this when a customer booking needs attention.

Before:

- find correct booking
- check customer, product, location, time

After:

- reply to customer or take visible app action

## Review Subscription

Use this when recurring access needs attention.

Before:

- check customer
- check product
- check current period and renewal
- check related bookings

After:

- decide whether the issue affects now, the next period, or both

## Handle Refund Work

Use this when a refund request or refund state needs review.

Before:

- check booking/subscription
- check payment state
- check policy and timing
- confirm whether action is available

After:

- record or communicate the next step without exposing payment secrets

## Connect Payments

Use this when the organization needs payment setup.

Before:

- authorized payment owner is signed in
- organization context is correct
- provider flow is approved

After:

- check setup status
- do not share payment credentials
