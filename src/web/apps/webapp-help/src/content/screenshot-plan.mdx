# Customer Screenshot Plan

Screenshots will be added later. Use this plan when capturing them.

## Capture Rules

- Use clean demo data.
- Hide customer email addresses unless they are fake demo emails.
- Hide payment details.
- Do not show access tokens or provider secrets.
- Capture the full page area needed to explain the step.
- Keep the screenshot close to the matching guide step.

## Required Screenshots

| Guide section                    | Screenshot to capture    | Notes                                              |
| -------------------------------- | ------------------------ | -------------------------------------------------- |
| Find a marketplace organization  | Public organization page | Show location and product entry points.            |
| Review a location                | Location detail page     | Show public info and floor plan link if available. |
| Review a product                 | Product detail page      | Show book/subscribe entry points.                  |
| Make a one-time booking          | Booking form             | Show date/time and summary, no payment secrets.    |
| Start a subscription             | Subscription form        | Show schedule and policy summary.                  |
| Check a booking                  | Booking detail page      | Show status and customer actions.                  |
| Check a subscription             | Subscription detail page | Show recurring schedule/status.                    |
| Request cancellation/refund help | Eligible detail page     | Show action area only with demo data.              |
| Notifications/settings           | Entry points             | Show where users go next.                          |

## Demo Data Suggestions

Use names like:

- Downtown Day Pass
- Meeting Room A
- Demo Co-working
- demo.customer@example.com

Avoid real organizations, real customers, and real booking references.

## Screenshot Review

Before adding each screenshot:

1. Check that it matches the current UI.
2. Check that it does not expose sensitive data.
3. Check that the surrounding guide text still matches the screenshot.
4. Update text if the UI label changed.
