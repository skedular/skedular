# Customer Page Reference

This page explains what each main Customer page is for, what to check there, and where to go next.

## Customer Home

Use the customer home when you are starting from the public customer app.

What to check:

- public marketplace entry points
- sign-in state
- links to marketplace organizations
- any next step the app shows

Go next to a marketplace organization, location, product, booking, or subscription.

## Marketplace Organization Page

Use this page when you want to browse one operator's public marketplace.

What to check:

- organization name
- available locations
- available products
- whether the page looks like the operator you expected

Go next to a location or product.

## Location Detail Page

Use this page to understand a place before choosing a product.

What to check:

- location name
- address or place details
- public description
- resources or spaces when shown
- floor plan link when available
- products connected to the location

Go next to a product page.

## Floor Plan Page

Use this page to understand the layout.

What to check:

- zones
- resource placement
- how the space is arranged
- whether the layout matches what you need

Go next back to the location or product. The floor plan helps you choose, but the product page confirms what you can book.

## Product Detail Page

Use this page before booking or subscribing.

What to check:

- product name
- description
- location or resource
- one-time booking option
- subscription option
- visible rules
- visible price or payment information
- cancellation or refund notes when shown

Go next to book or subscribe.

## Product Booking Page

Use this page to make a one-time booking.

What to check:

- product
- location
- date
- start and end time
- quantity or capacity if shown
- summary before confirmation

Go next to confirmation, then booking detail.

## Product Subscription Page

Use this page to start recurring access.

What to check:

- recurring product
- schedule
- renewal information
- visible payment information
- visible cancellation policy
- summary before confirmation

Go next to confirmation, then subscription detail.

## Bookings List

Use this page to find customer bookings.

What to check:

- upcoming bookings
- older bookings
- status
- location or product name
- date and time

Go next to booking detail.

## Booking Detail Page

Use this page when you need the exact booking record.

What to check:

- product
- location
- date and time
- status
- payment or confirmation state when shown
- visible customer actions
- cancellation or refund guidance when shown

Go next to the visible action, support, or back to the bookings list.

## Subscriptions List

Use this page to find recurring customer purchases.

What to check:

- active subscriptions
- canceled subscriptions
- product name
- status
- renewal or schedule information when shown

Go next to subscription detail.

## Subscription Detail Page

Use this page when you need the exact subscription record.

What to check:

- product
- recurring schedule
- current status
- related bookings when shown
- renewal information
- cancellation action when shown
- refund or support guidance when shown

Go next to the visible action, support, or back to the subscriptions list.

## Notifications Page

Use this page to review account updates.

What to check:

- recent booking updates
- subscription updates
- account messages
- integration messages
- links back to the related record

Go next to the related booking, subscription, or settings page.

## Settings Page

Use this page to review account preferences available to you.

What to check:

- account details
- preferences
- notification settings when shown
- sign-in/account actions when shown

Go next back to the workflow you were doing.

## Welcome Page

Use this page after sign-in or onboarding.

What to check:

- suggested next step
- account readiness
- link back to marketplace browsing

Go next to marketplace browsing or the page that sent you to sign in.

## Unsupported Page

Use this page as a signal that the link could not be opened safely.

What to check:

- whether the link was copied correctly
- whether the link belongs to Customer, Teams, or Spaces
- whether the operator has a newer marketplace link

Go next to the public marketplace organization page or operator support.
