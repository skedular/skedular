# Contracts: Smart Organization Landing Page

**Feature**: 015-smart-org-landing-page

---

## Overview

This feature introduces no backend API contract changes. All contracts are **frontend-only**:
new Relay GraphQL fragments (TypeScript) and a new `hideSideNav` prop on the shared
`NoOrganizationRootShell` component in all three apps.

---

## 1. New Relay Fragment — `noOrganizationLandingContent_query`

### Source (hand-authored, per app)

**webapp-teams** (`web/apps/webapp-teams/src/components/noOrganizationLanding/no-organization-landing-content.tsx`):

```graphql
fragment noOrganizationLandingContent_query on Query {
  myOrganizations(types: [PRIVATE]) {
    name
    uniqueId
    customDomain
    logoUrl
  }
}
```

**webapp-spaces** (`web/apps/webapp-spaces/src/components/noOrganizationLanding/no-organization-landing-content.tsx`):

```graphql
fragment noOrganizationLandingContent_query on Query {
  myOrganizations(types: [MARKETPLACE]) {
    name
    uniqueId
    customDomain
    logoUrl
  }
}
```

> **Note**: After authoring the fragment source, run `pnpm relay` in each app directory to
> generate Relay typed artifacts under `src/queries/__generated__/`. Never hand-edit
> `*.graphql.ts` files.

### Generated TypeScript shape (after `pnpm relay`)


## 2. New Page-Level Root Query — `noOrganizationLandingPage_rootQuery`

### Source (hand-authored, per app landing page)

**webapp-teams** and **webapp-spaces** — `src/rootPages/page.tsx`:

```graphql
query noOrganizationLandingPage_rootQuery {
  ...noOrganizationLandingContent_query
  me {
    isOnboardingDone
  }
}
```

This query is loaded at the page level using `useQueryLoader` + `loadQuery` in `useEffect`,
mirroring the pattern in `web/apps/webapp/src/rootPages/page.tsx` (`pageHome_rootQuery`).

## 3. Modified Component Prop — `NoOrganizationRootShell`

All three apps expose the same root shell component with an additional optional prop:

### Before

```typescript
interface RelayProps {
  collapsed?: boolean;
  // ...other existing props
}
```

### After

```typescript
interface RelayProps {
  collapsed?: boolean;
  hideSideNav?: boolean; // NEW — omits <NoOrganizationLeftSideNavigationMenu> from DOM
  // ...other existing props
}
```

### Behaviour contract

| `hideSideNav`     | `collapsed`       | Result                                           |
| ----------------- | ----------------- | ------------------------------------------------ |
| `true`            | any               | Left nav not rendered (absent from DOM)          |
| `false` / omitted | `true`            | Left nav rendered in collapsed (icon-only) state |
| `false` / omitted | `false` / omitted | Left nav rendered expanded                       |

### Callers

| App           | Call site            | Value         |
| ------------- | -------------------- | ------------- |
| webapp-teams  | `rootPages/page.tsx` | `hideSideNav` |
| webapp-spaces | `rootPages/page.tsx` | `hideSideNav` |
| webapp        | `rootPages/page.tsx` | `hideSideNav` |

All other callers of `NoOrganizationRootShell` remain unchanged (no `hideSideNav` prop → left
nav rendered as before).

## 4. New Component — `NoOrganizationLandingContent`

### File locations

| App           | Path                                                                                              |
| ------------- | ------------------------------------------------------------------------------------------------- |
| webapp-teams  | `web/apps/webapp-teams/src/components/noOrganizationLanding/no-organization-landing-content.tsx`  |
| webapp-spaces | `web/apps/webapp-spaces/src/components/noOrganizationLanding/no-organization-landing-content.tsx` |

### Props

```typescript
interface NoOrganizationLandingContentProps {
  queryRef: PreloadedQuery<noOrganizationLandingPage_rootQuery>;
}
```

### Rendered states

| State      | Trigger                        | Key elements                                                                                                                                    |
| ---------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `no-orgs`  | `myOrganizations.length === 0` | Heading, description, "Create organization" button → `getOrganizationSetupLink(integratedPlatform)`                                             |
| `has-orgs` | `myOrganizations.length >= 1`  | Heading, list of org cards, each card: `OrganizationAvatar` + org name, clickable → `getOrganizationBaseLink(integratedPlatform, org.uniqueId)` |
