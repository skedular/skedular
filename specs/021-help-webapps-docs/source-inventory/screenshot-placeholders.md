# Screenshot Placeholder Rules

Use screenshot placeholders in task guides where a visual check will help a reader.

## Wording

Use this exact pattern:

```text
> Screenshot needed: [short description of the screen or control to capture later.]
```

## Rules

- Keep the placeholder visible in the guide until the screenshot is captured.
- Describe the screen, not internal implementation details.
- Do not include fake image paths.
- Do not include customer names, payment details, emails, tokens, or private organization data in future screenshots.
- Use clean demo data when screenshots are added.

## First-Version Placement

Placeholders are required in:

- Customer guides for discovery, location detail, product detail, booking, subscription, booking detail, subscription detail, settings, and notifications.
- Teams guides for organization entry, bookings, locations, resources, teams, members, settings, integrations, analytics, availability, and SSO.
- Spaces guides for marketplace setup, locations, resources, products, bookings, subscriptions, refunds, payments, integrations, analytics, and availability.
