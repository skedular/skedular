# Implementation Plan: Remove Marketplace from Web App Teams

**Branch**: `feature/012-teams-marketplace-cleanup` | **Date**: 2026-05-24 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/012-teams-marketplace-cleanup/spec.md`

## Summary

Remove all marketplace-related UI, data, and proxy configuration from
`web/apps/webapp-teams`. This is a frontend-only cleanup with no backend schema
changes. The work spans 31 source files, 3 deleted generated artefacts, and a
Relay compiler re-run. The key outcomes are: product tags removed from all resource
and floor plan surfaces; marketplace booking subscriptions removed from booking
queries; marketplace bookings filtered out of the booking list at render time;
marketplace proxy routes and customer record sync check removed from the app shell.
