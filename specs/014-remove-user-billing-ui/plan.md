# Implementation Plan: Remove User-Level Billing & Payment UI

**Branch**: `014-remove-user-billing-ui` | **Date**: 2026-05-24 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/014-remove-user-billing-ui/spec.md`

## Summary

Remove the user-level "My Billing & Payment" UI surfaces from `webapp` and `webapp-teams`. This is a pure frontend deletion — routes, component directories, navigation entries, profile dropdown items, and orphaned Relay artifacts are removed. The backend remains unchanged. Organisation-level billing management is explicitly preserved. `webapp-spaces` was already cleaned in feature 013.
